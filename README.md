# V-Quant Pro

App Streamlit con analisi fondamentale, tecnica, quant e gestione portafoglio.

## Avvio locale

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy su Streamlit Community Cloud

1. Carica `app.py`, `requirements.txt` e il logo nel repository GitHub.
2. Vai su share.streamlit.io o su Streamlit Community Cloud dal tuo account.
3. Collega GitHub e seleziona il repository.
4. Come main file indica `app.py`.
5. Avvia il deploy.
